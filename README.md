# Neighborhood Builders - Construction Company Website

A modern, visually stunning website for Neighborhood Builders, a London-based construction company specializing in home renovations and extensions.

## 🚀 Features

- **Modern Design**: Clean, professional design with dark neutrals and gold accents
- **Responsive**: Fully responsive across all devices
- **Animations**: Smooth Framer Motion animations and transitions
- **SEO Optimized**: Proper meta tags and semantic HTML
- **Fast Loading**: Optimized for performance
- **Interactive Elements**: Hover effects, live chat widget, and smooth scrolling

## 🛠️ Tech Stack

- **React** - Frontend framework
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations
- **React Router** - Navigation

## 🏃‍♂️ Getting Started

1. **Clone or download** this project to your local machine

2. **Navigate to the project directory**:
   ```bash
   cd neighborhood-builders-website
   ```

3. **Install dependencies**:
   ```bash
   npm install
   ```

4. **Start the development server**:
   ```bash
   npm run dev
   ```

5. **Open your browser** and visit `http://localhost:5173`
